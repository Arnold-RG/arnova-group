# Brand

The live site mark is **logo v7 C2**: an ingabo (shield) on the left, a celebrating figure over a wide letter A in the centre, and an icumu (spear) on the right, with a subtle Imigongo pattern on the shield. Files live in `logo-v7/`.

Light theme uses the pewter mark and ink wordmark; dark theme uses the platinum mark and platinum wordmark. `logo.svg` at the repository root is a theme-aware favicon (pewter on light, platinum on dark). PNG fallbacks are `favicon-16.png`, `favicon-32.png`, and `apple-touch-icon.png` (180px, pewter on paper).

## Palette

The live layout uses the Signal Slate token set. Edit `css/tokens.css` and change the single import only if a previous palette is needed.

Earlier review options remain in `option-1/` (Apex Navy), `option-2/` (Ridge Forest) and `option-3/` (Signal Slate). Each folder has mark and wordmark files for light and dark.
